DŘÍMOVNA — DEMO v1.2 (10. 10. 2026)

Součásti: index.html, styles.css, app.js, assets/, robots.txt a _headers.
Projekt Netlify: drimovna, účet valerijsorban1@gmail.com.

Demo je určeno pro ukázku dodavatelům a vizuální revizi.
Novinky: headline „Spalo se ti dobře?“, zmenšený titulek, trvale viditelné hledání desktop/mobil s návrhy produktů a vyhledáváním podle rozměrů, tlačítko „Prohlédnout kolekce“.
Žádné objednávky ani platby. Formulář je v DEMO režimu: bez odeslání; WhatsApp číslo není nastaveno. Nenechávat skutečné zákazníky objednávat.
Právní stránky jsou pouze návrh a zobrazené ceny/produkty ukázkové. Ilustrace produktů jsou lokální SVG, fotografie kočky je lokální WebP.

Pro ruční deploy Netlify: přetáhnout do projektu složku obsahující index.html a další soubory. ZIP je exportním balíčkem; před uploadem jej rozbalte.
